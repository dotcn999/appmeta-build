一条路径，三个动作

从钥匙串里的 .p8，到识别工程与描述文件，再到 Archive 导出上传。

  1. 01

    配置 API Key

    Key ID、Issuer ID 与 AuthKey .p8 写入本机钥匙串，不落明文目录。

  2. 02

    识别工程与签名

    选 .xcodeproj / workspace，匹配 Scheme、描述文件与证书。

  3. 03

    Archive 并投递

    一键 Archive → 导出 IPA → 上传 App Store Connect，日志实时可见。
