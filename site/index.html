少切窗口，多出包

不用在 Xcode、钥匙串、Transporter 之间来回跳。选好工程与描述文件后，本机一条路径跑完 Archive、导出和上传。

怎么用

  1. 1

    放好 API Key

    填写 Key ID、Issuer ID，选择 AuthKey .p8。私钥进钥匙串，不落明文目录。

  2. 2

    识别工程与签名

    选择 .xcodeproj / workspace，确认 Scheme、描述文件与证书就绪。

  3. 3

    导出并上传

    一键 Archive → 导出 IPA → App Store Connect；右侧日志实时跟进。
